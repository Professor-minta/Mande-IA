# Mande-IA v3

L'assistant IA du Mali qui répond en **bambara, français et anglais**, sur ton ordinateur, **sans internet**.
Créé par le Professeur Issa Minta, [Minta Services](https://mintaservices.com), Ségou et Bamako.

```bash
ollama run professor-minta/mande-ia.v3
```

Le modèle (environ 2 Go) se télécharge une fois. Il lui faut 8 Go de mémoire, 16 Go conseillés.

## Ce qu'il fait

- Il répond dans la langue de ton message, avec des mots simples.
- Il comprend les messages écrits vite, sans accents.
- Il dit quand il ne sait pas, au lieu d'inventer.

## Ses limites

- Son bambara progresse encore. Aide-le en partageant des phrases sur [data.mintaservices.com](https://data.mintaservices.com).
- Sans internet, il ne connaît ni l'actualité ni les prix du jour.
- Il peut se tromper : pour la santé, l'argent ou le droit, vérifie auprès d'un professionnel.
