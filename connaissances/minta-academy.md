## Minta Academy en ligne
Minta Academy est la formation de Minta Services. Les cours en ligne sont gratuits, sans inscription : https://mintaservices.com/academy/. Il y a 10 modules pratiques, en cinq phases : Fondations, Infrastructure, Développement, Intelligence artificielle et Projet final. Chaque module se termine par un exercice et une partie « Vérifie que tu sais ». Les élèves notent leur travail dans un dossier `notes/`, un fichier par module.

## Les 10 modules
1. Méthode de travail et sécurité (2 heures) : organiser son dossier de travail, les mots de passe, la double authentification, les clés SSH, les 5 règles absolues, reconnaître une arnaque. Page : https://mintaservices.com/academy/01-methode-securite.html
2. Git et GitHub (3 heures) : installer Git, les 4 commandes de tous les jours, le fichier .gitignore, sécuriser son compte GitHub, envoyer un projet, branches et Pull Requests, réparer une erreur. Page : https://mintaservices.com/academy/02-git-github.html
3. Domaines et DNS (2 heures) : choisir un bon nom, acheter le domaine, les enregistrements DNS, relier le domaine au serveur, vérifier que ça marche. Page : https://mintaservices.com/academy/03-domaines-dns.html
4. Ton serveur VPS sur DigitalOcean (3 heures) : créer le Droplet, première connexion, créer son utilisateur, le pare-feu, interdire la connexion par mot de passe, les mises à jour de sécurité automatiques, la surveillance et les sauvegardes. Page : https://mintaservices.com/academy/04-serveur-vps.html
5. aaPanel, sites web et HTTPS (3 heures) : installer et sécuriser aaPanel, installer le serveur web, mettre un site en ligne, le HTTPS avec Let's Encrypt. Page : https://mintaservices.com/academy/05-aapanel.html
6. Node.js, de ton ordinateur au serveur (4 heures) : un projet propre, le serveur, GitHub, le déploiement avec aaPanel et la mise à jour de l'application. Page : https://mintaservices.com/academy/06-nodejs.html
7. Python et automatisation (3 heures) : un environnement par projet, les bases, trois scripts (sauvegarder un dossier, vérifier que des sites répondent, calculer des totaux dans un CSV), lancer un script tout seul sur le serveur. Page : https://mintaservices.com/academy/07-python-automatisation.html
8. IA locale avec Ollama et Mande-IA v3 (3 heures) : installer Ollama, lancer `ollama run professor-minta/mande-ia.v3`, les commandes Ollama, l'API sur http://localhost:11434, créer son propre assistant avec un Modelfile. Le modèle pèse environ 2 Go ; 8 Go de mémoire au minimum, 16 Go conseillés. Page : https://mintaservices.com/academy/08-ollama-mande-ia.html
9. Open WebUI, une IA hors ligne pour toute l'équipe (3 heures) : installer Open WebUI (Python 3.11 ou 3.12), l'ouvrir sur http://localhost:8080, travailler sans internet, utiliser ses documents, toute l'équipe sur le même réseau, la version Docker pour un serveur. Page : https://mintaservices.com/academy/09-open-webui.html
10. Construire et présenter ton projet (1 à 2 semaines) : choisir un vrai problème du Mali, planifier, la liste de sécurité, présenter en 5 minutes. Page : https://mintaservices.com/academy/10-projet-final.html

## Les 5 règles absolues
1. Les clés et mots de passe ne vont jamais dans un message, ni WhatsApp, ni e-mail, ni chat avec une IA.
2. Les fichiers .env ne vont jamais sur GitHub : on les ajoute au fichier .gitignore.
3. On recadre les captures d'écran avant de les partager : pas d'adresse IP, pas de port de panneau, pas de lien de session, pas de clé.
4. Une clé exposée est une clé perdue : on la remplace tout de suite.
5. On sauvegarde avant de modifier : un instantané du serveur ou une copie du fichier.

## Le projet final
Le projet doit contenir : un dépôt GitHub propre avec un README et sans aucun secret ; une adresse en ligne en HTTPS ; une partie serveur en Node.js ou en Python ; une partie automatique (tâche Cron) ou intelligente (IA locale) ; une sauvegarde. Il est noté sur 20 : vrai problème clairement expliqué (4 points), fonctionne en ligne en HTTPS (4), partie serveur et partie automatique ou IA (4), sécurité (3), code et README propres (3), présentation claire dans le temps (2).

## Aider un élève bloqué
- Demander le numéro du module, l'étape et le message d'erreur exact, recopié en texte. Ne jamais demander de clé, de mot de passe ni de capture qui montre une adresse IP.
- « Already up to date » après git pull : la Pull Request n'est pas encore fusionnée sur GitHub.
- Une modification ne s'affiche pas : redémarrer le projet Node dans aaPanel, puis recharger la page avec Ctrl+F5.
- Un domaine qui ne répond pas : vérifier l'enregistrement A, puis attendre la propagation du DNS, souvent moins d'une heure.
- Un site injoignable : vérifier le pare-feu du serveur et celui d'aaPanel pour le port concerné.
- Coller une commande : copier seulement la commande, jamais le texte d'explication autour.
